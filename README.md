# WH40K Armory

Tienda online ficticia de armas del universo Warhammer 40,000.
Evaluación Parcial 2 – DSY1104 Desarrollo Fullstack II (Duoc UC).

## Tecnologías
React 19 + Vite, Bootstrap 5 / React-Bootstrap, React Router, react-hook-form,
Jasmine + Karma (pruebas unitarias).

## Cómo ejecutar
npm install
npm run dev

## Pruebas
npm run test

## Aviso
Proyecto académico sin fines comerciales. Las imágenes son placeholders;
no se usa arte oficial de Games Workshop.
